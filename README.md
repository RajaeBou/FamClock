# FamClock

## Objectif
Ce projet vise à concevoir une horloge familiale intelligente permettant d’indiquer visuellement la localisation des membres du foyer sans utiliser d’écran.

## Contexte
Projet réalisé dans le cadre du TFE à l’EPHEC.

## Technologies principales
- Raspberry Pi
- Python
- Servomoteurs (PWM)
- Interface Web

## Méthodologie
Approche Agile avec gestion par EPICs, User Stories et Sprints.
